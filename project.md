**1. Smart Tutoring System**

**Description:**

The Smart Tutoring System (STS) is an intelligent, modular application designed to personalize learning experiences for students across various subjects. It dynamically adapts to individual performance, learning styles, and progress, offering tailored content, assessments, and feedback. The system leverages core object-oriented programming (OOP) principles to ensure scalability, maintainability, and pedagogical integrity.

- A system that adapts to student performance using polymorphic question types and inheritance-based user roles (student, tutor, admin).

- Tracks progress, recommends lessons, and generates quizzes dynamically.
